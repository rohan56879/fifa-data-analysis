# FIFA Data Analysis

## 📊 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on FIFA player data using Python. The goal is to explore player attributes, identify top-performing players, analyze relationships between different variables, and visualize important insights from the dataset.

## 🎯 Objectives

The main objectives of this project are:

* Analyze FIFA player data
* Explore player age distribution
* Identify top players based on different attributes
* Analyze player acceleration, strength, dribbling, and defending
* Calculate potential growth
* Find correlations between numerical features
* Create meaningful data visualizations

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Features Analyzed

The project includes analysis of the following features:

* Age
* Overall Rating (OVA)
* Potential Rating (POT)
* Player Value
* Wage
* Potential Growth
* Acceleration
* Strength
* Dribbling
* Defending

### Potential Growth

Potential growth is calculated as:

```text
Potential Growth = Potential Rating - Overall Rating
```

## 📈 Data Analysis Performed

Some of the analysis performed in this project includes:

* Age distribution of players
* Top players based on acceleration
* Player strength analysis
* Potential growth analysis
* Grouping and aggregation using Pandas
* Correlation analysis between numerical variables
* Identification of relationships between player attributes

## 📉 Visualizations

These visualizations help identify patterns and relationships between player attributes.

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/rohan56879/fifa-data-analysis.git
```

2. Navigate to the project folder:

```bash
cd fifa-data-analysis
```

3. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

4. Open the Jupyter Notebook:

```bash
jupyter notebook
```

5. Run the `fifa_analysis.ipynb` notebook.
